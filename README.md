# Planner

**Planner** — настольное приложение для Windows, предназначенное для управления напоминаниями и планирования повседневных задач с помощью ИИ.

Приложение поддерживает обычные и повторяющиеся напоминания, расписание и уведомления, а AI-планировщик позволяет создавать и изменять напоминания с помощью текстовых запросов.

## Скачать

**[Скачать Planner для Windows](https://github.com/HopRomh/planner-releases/releases/latest)**

На странице релиза скачайте файл `Planner_0.1.0_x64-setup.exe` и запустите его.

Windows может предупредить о неизвестном издателе, поскольку установщик пока не подписан сертификатом. Запускайте его только если доверяете источнику.

## Возможности

- **Напоминания:** создание, выполнение и удаление задач.
- **Повторения:** ежедневное, еженедельное и ежемесячное расписание с настройкой интервалов и дней недели.
- **Уведомления:** отдельные окна с действиями «Готово» и «Отложить на 5 минут».
- **AI-планировщик:** создание и изменение напоминаний с помощью текстовых запросов.
- **Расписание:** просмотр задач на сегодня, завтра и ближайшую неделю.
- **Настройка интерфейса:** темы оформления и изменение ширины боковой панели.

## Настройка ИИ
<img width="1919" height="1079" alt="изображение" src="https://github.com/user-attachments/assets/b0128d6e-b3b4-41d3-8408-b89b0c15d434" />

Для AI-функций требуется API-ключ совместимого провайдера.

В настройках приложения укажите:
1. Базовый URL API.
2. Название модели.
3. API-ключ.
4. Таймаут запросов.

Planner использует OpenAI-совместимый API с endpoint `/chat/completions`. Поддержка конкретной модели зависит от выбранного провайдера.

**Обратите внимание:** API может быть платным. Стоимость запросов и ограничения определяются провайдером. Не передавайте API-ключи посторонним.

## Хранение данных и конфиденциальность

Напоминания и настройки хранятся локально на компьютере. API-ключ сохраняется в системном хранилище учётных данных Windows.

При использовании AI текст запроса отправляется выбранному пользователем API-провайдеру. Автоматической облачной синхронизации между устройствами нет.
